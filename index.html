Rust · InChI · byte-exact

A native InChI engine, gated by the oracle it was built against.

chemomer reads molfiles and derives InChI, AuxInfo, and InChIKey — byte-exact with the IUPAC InChI 1.07.5 reference implementation. Every release passes the same conformance corpus the oracle recorded; a difference is a failing gate, not a footnote.
